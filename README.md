# Welcome to Utrecht Centre for Sustainable Use of the Subsurface

Welcome at **GitHub@USustSub**! 
The [Utrecht Centre for Sustainable Use of the Subsurface](https://www.uu.nl/en/research/department-of-earth-sciences/research/sustainable-use-of-the-subsurface) contributes to sustainable, responsible, and safe use of the subsurface, supporting the global energy transition. This GitHub is our place where we develop and share research code, software, and others.
